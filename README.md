# Ori Fitness App

אפליקציית PWA אישית לכושר ותזונה. עברית, RTL, מותקנת בטלפון.
**כל הנתונים נשמרים מקומית במכשיר בלבד** (IndexedDB) — בלי שרת, בלי ענן, בלי עלויות.

---

## הרצה מקומית (במחשב)

האפליקציה **חייבת** לרוץ דרך שרת (לא בפתיחת הקובץ ישירות) — IndexedDB
ו-Service Worker חסומים ב-`file://`.

```bash
powershell -ExecutionPolicy Bypass -File serve.ps1
```

ואז לפתוח בדפדפן: `http://localhost:8080`
לעצירה: `Ctrl+C`. לפורט אחר: `serve.ps1 -Port 8081`

## פריסה ל-GitHub Pages

האתר כבר פרוס וחי:

- **דף הבית:** https://ori-ak-fitness.github.io/ori-fitness-app/
- **האפליקציה:** https://ori-ak-fitness.github.io/ori-fitness-app/app/

מבנה: `index.html` בשורש הוא דף הנחיתה השיווקי (עצמאי, בלי תלויות),
וכל האפליקציה עצמה יושבת תחת `app/` — כולל `css/`, `js/`, `icons/`,
`sw.js` ו-`manifest.json`. כל הנתיבים באפליקציה יחסיים, ולכן ההעברה
לתת-תיקייה לא דרשה שינוי קוד.

הפריסה אוטומטית לחלוטין — כל דחיפה ל-`main` מריצה את
`.github/workflows/pages.yml`, שמפרסם מחדש את האתר תוך כדקה:

```bash
git add .
git commit -m "תיאור השינוי"
git push
```

אין צורך להדליק Pages ידנית בהגדרות: ה-workflow משתמש ב-`configure-pages`
עם `enablement: true`, ולכן הוא מפעיל את Pages בעצמו.

GitHub Pages מגיש ב-HTTPS, ולכן גם המצלמה החיה והתקנת ה-PWA עובדות.
כל הנתיבים בפרויקט יחסיים, כך שזה עובד גם בתת-נתיב (`/ori-fitness-app/`).

### התקנה בטלפון

- **אנדרואיד (Chrome):** פתח את הכתובת → תפריט ⋮ → "Install app" / "הוסף למסך הבית"
- **אייפון (Safari):** פתח את הכתובת → כפתור שיתוף → "הוסף למסך הבית"

### עדכון גרסה

אחרי `git push` של שינויים, העלה את `CACHE_VERSION` ב-`sw.js`
(למשל `ori-fitness-v1` → `ori-fitness-v2`) כדי שהמטמון הישן יימחק בכל המכשירים.

## מה כבר בנוי (שלב 1)

- **תשתית PWA**: manifest, Service Worker, עבודה מלאה אופליין, אייקונים
- **תוכניות אימון**: בונים "אימון A", "אימון B" עם רשימת תרגילים ומספר סטים,
  ומשבצים אותם לימי השבוע. נכנסים לאימון והתרגילים כבר מוכנים
- **זיכרון משקלים**: כל תרגיל נטען עם המשקל מהפעם הקודמת, וכתוב מעליו מה עשית אז
- **אירובי**: סוגים שמגדירים פעם אחת, סימון בלחיצה, כמה פעמים שרוצים ביום
- **תפריט יומי קבוע**: מגדירים את הארוחות פעם אחת, וכל יום רק מסמנים מה נאכל.
  "התפריט של היום" יושב בראש מסך התזונה (מעל טבעת הקלוריות) עם תג
  קלוריות-היום למעלה, ובגודל מוגדל יותר לקריאות
- **תוכן ארוחה כתוב**: לכל פריט במאגר (וגם לארוחות חופשיות) אפשר לרשום
  טקסט חופשי — בדיוק מה יש בצלחת — ולפתוח אותו מ"תפריט מלא 📄" בלי
  לגעת בסימון "אכלתי", למי ששוכח מה התוכנית בעל פה
- **מסך בית**: ציטוט מוטיבציה יומי, ממורכז אנכית ואופקית עם גרשיים, עם
  תמונת רקע (כפתור 📷 קבוע על הכרטיס להוספה, לחיצה על התמונה לצפייה/
  מחיקה — בלי גלריה נפרדת), רשימת "🏹 מטרות" ממוספרת וקבועה (נפרדת
  מהציטוט המתחלף — עריכה דרך ההגדרות בלבד), כרטיס "תזונה היום" (קלוריות
  + מאקרו, בסדר: פחמימות/שומן/חלבון) למעלה, וכרטיס "אימונים השבוע"
  (X מתוך יעד שבועי + פירוט לכל סוג אירובי) מתחתיו
- **דף מנטלי** (בהגדרות): ניהול תמונות הרקע, ורשימת כל 40 הציטוטים
  הקבועים (מפורסמים בעולם הספורט) ממוספרים לפי הסדר, לקריאה בלבד —
  אין עוד אפשרות להוסיף ציטוטים אישיים. אותו ציטוט מופיע גם כתזכורת
  קטנה בתוך אימון פעיל
- **התפריט המלא שלי** (בראש מסך התזונה): הערה קבועה אחת בטקסט חופשי —
  לא לפי יום — למי ששוכח מה אמור לאכול. נפרד מה"תפריט מלא 📄" הפרטני
  שיושב על כל פריט במאגר המזון
- **יומן אימונים**: תרגילים חופשיים (בלי רשימה מוגדרת מראש), סטים/משקל/חזרות
- **מעבר אוטומטי בין שדות**: אחרי הפסקה קצרה בהקלדה (~1 שנ'), או מיידית עם Enter / "הבא"
- **טיימר חי** מהתחלת האימון ועד סיומו — שורד סגירת אפליקציה
- **סיכום אוטומטי**: משך, מספר סטים ותרגילים + חגיגת סיום (נפח האימון לא מוצג
  יותר בזרימת האימון — נשאר רק כגרף ב"התקדמות", למי שרוצה להסתכל שם)
- **שיא אישי — משקל וגם חזרות**: ברגע שסט עובר את המשקל הכי כבד או את
  מספר החזרות הכי גבוה שביצעת אי־פעם בתרגיל, קופצת התראת 🏆 (עם תיוג
  נפרד ל"שיא חדש" מול "שיא חזרות חדש"). הסט מסומן, האימון מקבל תגית
  בהיסטוריה, והשיאים מחושבים מחדש בכל רינדור (מחיקת אימון מזיזה אותם)
- **גרפי התקדמות**: משקל מקסימלי לכל תרגיל לאורך זמן, ונפח לכל אימון —
  ומתחת לגרף התרגיל, רשימה קריאה עם תאריך מדויק/משקל/חזרות לכל רישום,
  בלי צורך לרחף על הגרף
- **יומן שקילות**: רישום משקל גוף יומי, גרף התקדמות, ושינוי מהשקילה הראשונה
- **יומן תזונה**: יעדים לפי תאריך תחילה (חיטוב/מסה), ארוחות עם תמונה, עריכה,
  "נותרו X קלוריות" והתראת חריגה, מעקב מאקרו

## שינוי הלוגו

הלוגו הנוכחי (`icons/logo.svg` + שלושת קבצי ה-PNG ב-`icons/` + `icons/app.ico`)
הוא משקולת בקרם ושחור עם "ORI FITNESS" בכתב סריפי מעודן (Georgia, ריווח אותיות
רחב) מתחת, בערכת הצבעים הבהירה של האפליקציה.

**חשוב לגבי `icons/app.ico`**: זה האייקון שקיצור הדרך בשולחן העבודה
("הפעל Ori Fitness.lnk") מצביע עליו ישירות — הוא **נפרד לגמרי** מהאייקונים
של ה-PWA (icon-192/512/מסכה). אם מעדכנים לוגו, חובה לעדכן גם את הקובץ הזה,
אחרת קיצור הדרך בשולחן העבודה ימשיך להראות את האייקון הישן. וגם אז —
Windows שומר cache לאייקונים של קיצורי דרך; אם העדכון לא נראה מיד, נסה
לרענן את שולחן העבודה (F5) או להתנתק ולהתחבר מחדש.

אם תרצה לעדכן שוב — עדכן קודם את `icons/logo.svg` (זו ה"אמת" הוקטורית), ואז
תאריך את שלושת ה-PNG וגם את ה-ICO כדי שיתאימו. כולם נוצרים עם סקריפט
PowerShell חד-פעמי שמצייר עם `System.Drawing`/GDI+ ישירות בגדלים הנדרשים —
לא ידנית, ולא דרך המרת base64 (זו התבררה כלא אמינה לקבצים גדולים).
