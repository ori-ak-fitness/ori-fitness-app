# design/

מוקאפים של מסכי האפליקציה — לא קוד רץ, ולא חלק מהאפליקציה עצמה.

`ori-fitness-screens.html` הוא דף אחד שמציג את ארבעת המסכים זה לצד זה
בגודל טלפון אמיתי (430 פיקסלים), כדי שאפשר יהיה להסתכל ולהחליט מה
לשנות בלי לתאר במילים. הוא מצויר מהערכים האמיתיים של `css/styles.css`
— אותם צבעים, גדלים, מרווחים ועיגולי פינות.

קבצי ה-`.dc.html` הם אותם מסכים כארטבורדים נפרדים, מוכנים לקנבס
העריכה של Claude Design. **הקנבס עצמו לא נבנה כאן** — הוא דורש Node,
ואין Node על המכונה הזו (ראה ARCHITECTURE.md: הפרויקט הוא בכוונה
ללא שלב בנייה).

**כשמשנים משהו באפליקציה, המוקאפים כאן לא מתעדכנים לבד.** אם הם
מציגים משהו שכבר לא נכון, עדיף לעדכן אותם מהקוד מאשר להשאיר מוקאפ
שמראה גרסה ישנה.
